### コインとショップの進み具合
- [x] 1回目：コインと🍅のしくみ、ショップ画面、色30種、和室・宇宙の有料化
- [x] 2回目：目・口・ほっぺ 各30種
- [x] 3回目：アクセサリー30種（頭・首まわり20、机の上10）
- [x] 4回目：部屋のテーマ15種

## 目標と振り返り
- 目標は「1週間の勉強時間」（例：週10時間）
- ロビーの上に「今週 6時間20分 / 10時間」の進捗バー。プロフィールにも出す
- ほかの人に見せるかは、統計の公開設定に合わせる
- 達成したらお祝いの演出＋コインのボーナス（🪙20）
- 月曜にロビーで「先週のまとめ」（合計・前の週との差・一番がんばった日・よく使ったタグ）

## 定例の部屋
- オーナーとモデレーターが、曜日（複数）と開始時刻を設定できる（例：平日の7:00）
- ロビーに「もうすぐ始まる定例」を30分前から出す。フォロー中の人の部屋と、参加したことのある部屋だけ
- 開始時刻にポモドーロのタイマーを自動で開始する
- 📬 のお知らせにも出す

## 実績バッジ
- まず20〜30個（初めての入室・朝活・夜ふかし・1日5時間・10ポモドーロ・連続14日・初フォロー・初スタンプ・テーマを買った など）
- バッジ＋少しのコイン（🪙5〜30）
- プロフィールに並べる（取っていないものはシルエット）。取った瞬間にお祝い
- 今の「解放アイテム」はそのまま残す（バッジとは別）

## ダークモード
- パソコン・スマホの設定に合わせるのが基本。設定画面で「自動・ライト・ダーク」を選べる
- もちの体の色はそのまま。影や机の色を夜向けに調整
- 部屋のテーマの絵はそのまま

## 記録のふり返りを詳しく
- 月ごとのグラフ（日ごとの棒）、時間帯ごとの集中（朝型・夜型）、曜日ごとの平均、タグ・部屋ごとの時間、1回あたりの平均時間
- 期間は 今週・今月・3か月・1年 で切り替え
- 「記録」ページの上にグラフ、下に今の一覧
- 自分だけに見える

## 見送ったもの

- YouTube の BGM（YouTube の規約上、プレーヤーを隠して音だけ流すことができないため）
