# ショップ カタログ案（たたき台）

コインは勉強10分で1枚（＋ポモドーロ完了・連続日数のボーナス）。部屋の🍅はその部屋でのみんなの勉強時間25分で1個。
値段のランク：**やさしい 5〜15** ／ **ふつう 20〜30** ／ **ちょっといい 40〜80** ／ **レア 150**（🪙＝コイン）

- **登録ボーナス**：新しく登録した人に最初から 🪙30（すぐに1つ買える）

- 「デザインのルール（点の目・小さな口・線の太さ統一）」は少しなら破ってよい
- 解放アイテム（葉っぱ・マグカップ・ランプ・観葉植物・ペットのミニもち・王冠・あい色ハチマキ）は売らない

## 決まったこと（買い方・ショップ）
- 頭の小物と首の小物は同時に付けられる（例：ねこみみ＋マフラー）
- 買ったものは返品できない。買う前に「本当に買いますか？」と確認し、試着できるようにする
- ショップの並び順は自分で選べる（値段の安い順・高い順・新しい順・持っていないものを先 など）
- 値段は最初の案の約半分（全部そろえるのに、1日1時間で約1年3か月・1日2時間で約8か月）
- 部屋のテーマ（🍅）の値段はそのまま
